## Naming Conventions

- **Classes**: PascalCase (e.g., `PlayerController`) — must also be `partial`
- **Variables**: Public properties/fields PascalCase (e.g., `MoveSpeed`); private fields `_camelCase` (e.g., `_currentHealth`)
- **Signals/Events**: PascalCase + `EventHandler` suffix (e.g., `HealthChangedEventHandler`)
- **Files**: PascalCase matching class (e.g., `PlayerController.cs`)
- **Scenes/Prefabs**: PascalCase matching root node (e.g., `PlayerController.tscn`)
- **Constants**: PascalCase (e.g., `MaxHealth`)
