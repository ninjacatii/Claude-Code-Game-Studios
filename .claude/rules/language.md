# 语言规则（Language）

本项目默认使用**简体中文**进行交流与撰写文档。

- **交流**：与用户的对话（提问、方案、审批请求、总结、报告）默认使用简体中文；
  子代理面向用户的输出同理。
- **生成文档**：`design/`、`docs/`、`production/`、`tests/` 下的说明性文档、
  测试报告、README、变更日志与补丁说明默认使用简体中文。
- **保持英文**：代码与标识符、文件路径、配置键/YAML 字段名、引擎与第三方 API
  名称、Conventional Commits 的类型前缀（`feat:`、`fix:` 等）、原样引用的
  报错与日志输出。
- **既有英文文档不追溯翻译**：不因本规则批量重写；编辑既有文档时沿用其现有
  语言，除非用户明确要求翻译。
- **框架内部文件保持英文**：`.claude/` 下的技能、代理、钩子与 `studio-tests/`
  维持现有英文，避免破坏框架约定；用户明确要求时再改。
- **代码注释**：沿用所在文件的既有语言；新建业务代码文件默认中文注释。

> 本文件刻意不写 `paths:` 前置元数据，以便每个会话都加载（见
> `.claude/docs/rules-reference.md`）。
